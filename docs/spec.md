# swingcheck 仕様書（草稿）

ゴルフスイングの動画から骨格を推定し、Pシステムのポジションごとにスイングを確認するスマートフォンアプリ。

## 1. 対象

- 利用者：ゴルファー本人と、コーチ・レッスンプロ
- プラットフォーム：Android と iOS
- 打席：右打ちのみ（左打ちは将来対応）
- 表示言語：日本語と英語。端末の言語設定に合わせて切り替える

## 2. Pシステム

P1〜P8 を対象とする。P9・P10 は扱わない。

| P | ポジション |
|---|---|
| P1 | アドレス |
| P2 | テークバックでシャフトが地面と平行 |
| P3 | 左腕が地面と平行 |
| P4 | トップ |
| P5 | 切り返し後、左腕が地面と平行 |
| P6 | ダウンスイングでシャフトが地面と平行 |
| P7 | インパクト |
| P8 | フォローでシャフトが地面と平行 |

### Pのコマ決め

- アプリが各Pのコマを自動で推定し、候補として表示する
- ユーザーはコマを前後に動かして修正できる

### シャフト推定

- 初期版：骨格（手首・前腕）の向きからシャフトの向きを推定する。精度は低めのため、コマの手動修正を前提とする
- 将来：グリップとクラブヘッドを検出するモデルを学習させて置き換える。差し替えられる構成にしておく

## 3. 撮影

### 撮影方向

- 初期版：正面（フェースオン）
- 将来：後方（ダウンザライン）。撮影方向ごとに判定ロジックと表示項目を切り替えられる構成にしておく

### 動画の取り込み

- 初期版：アプリ内のカメラで撮影する
  - 立ち位置を合わせるための人型のガイド枠を重ねて表示する。合っているかの判定はせず、ユーザーが自分で合わせる
  - フレームレートは、端末が対応しているいちばん高いもの（120fps、240fpsなど）を自動で使う。設定画面で変更できる
- 将来：端末に保存済みの動画を読み込む

### 録画の開始と停止

スイングを自動で検出して切り出す。

- カメラ映像の直近数秒分をメモリに保持する（リングバッファ）
- 間引いたフレーム（毎秒15コマ程度）で骨格推定を行い、アドレスで静止 → 大きな動き → フィニッシュで静止、という流れを検出したらスイングと判定する
- 検出したスイングの前後を動画ファイルとして保存する
- 素振りは保存しない。ボールを打ったかどうかは次のように判定する
  - アドレス（P1）のときに、足元のあたりでボールの位置を見つける
  - フィニッシュのころに、同じ場所にボールが残っているかを確かめる
  - ボールが消えていれば「打った」として保存し、残っていれば「素振り」として保存しない
  - ボールが見つからないなど判定できなかったときは保存する（不要なら一覧から削除してもらう）
  - この判定は設定画面でオフにできる。オフにすると素振りも保存する
- P1〜P8 の判定と数値の計算は、保存後に全コマを使って行う
- スイングを検出しても撮影画面のまま次のスイングを待つ
  - 画面の端に保存済みのスイング数（例：「3スイング保存済み」）を表示する
  - 結果はあとで一覧から見る
  - 保存後の解析は順番待ちにして裏で進める。撮影中に端末の負荷が高い場合は、撮影を終えてから解析する

## 4. 解析

- 解析はすべて端末内で行う
- 骨格推定：MediaPipe Pose Landmarker
- 将来：サーバーでの高精度な解析を有償オプションとして提供する。解析処理は差し替えられる構成にしておく

### 表示項目

各Pのコマで次を表示する。

日本語表示では、画面上の名前を「日本語（英語）」の形で併記する。英語表示では英語名だけを表示する。英語名はGEARSの呼び方に合わせ、GEARSに対応する項目がないものは一般的な呼び方にする。

| 項目（表示名） | 内容 |
|---|---|
| 骨格の線 | 関節を結んだ線を動画に重ねて描く |
| 頭の横移動（Head Sway） | P1 からの左右の移動量 |
| 頭の上下移動（Head Lift） | P1 からの上下の移動量 |
| 肩の傾き（Shoulder Tilt） | 左右の肩を結んだ線の角度 |
| 腰の傾き（Pelvis Side Bend） | 左右の腰を結んだ線の角度 |
| 腰の横移動（Pelvis Sway） | 腰の中心の、P1 からの左右の移動量 |
| 背骨の傾き（Spine Tilt） | 腰の中心と肩の中心を結んだ線の、鉛直からの傾き |
| 膝の角度（Knee Flex） | 左右の膝の曲がり具合 |
| 肘の角度（Elbow Flex） | 左右の肘の曲がり具合 |
| 推定シャフトの線 | 推定したシャフトを補助線として描く |

- 移動量は、GEARSと同じくアドレス（P1）の位置を0とする
- 2D骨格では胸郭の位置を直接取れないため、胸郭を使う項目は肩の中心で代わりにする

### 移動量の単位

- 体の大きさを基準にした比率（肩幅の◯%など）で常に表示する
- 身長が入力されている場合は、cm（約◯cm）もあわせて表示する
  - 身長はスイングごとに持ち、解析結果の画面で入力・変更できる。変更したらcmの数値を計算し直す
  - 設定画面に入力した身長を、新しく撮ったスイングの初期値にする（未入力なら空のまま）
  - 前傾や膝の曲がりの影響を受けにくい部位（肩幅、脚の長さなど）の画面上の長さを、身長から求めた長さと比べて換算する
  - 誤差が数cmあることを前提とした表示にする
  - 長さの単位（cm／インチ）は設定画面で選べる。初期値は端末の地域設定に合わせる。インチを選んだ場合、身長はフィート・インチで入力する
- 前後方向（ボールに近づく・離れる）の移動は、正面撮影では測らない

### その他

- 初期版では数値を表示するだけで、目安の範囲やお手本とは比較しない
- 将来の比較機能に備えて、各Pの数値はデータとして保存しておく

## 5. 画面

### 画面の流れ

- 起動すると撮影画面を表示し、すぐにカメラを立ち上げる
- 撮影画面のボタンからスイングの一覧を開く
- 一覧からスイングを選ぶと解析結果の画面を開く

### スイングの一覧

- 撮影日時の新しい順に並べる
- 各スイングは撮影日時だけを表示する（サムネイルは出さない）
- 削除：行を長押しすると選択モードに入り、複数の行を選んでまとめて削除できる（1件だけ選んで削除も可）
- 削除する前に確認のダイアログを出す

### 解析結果の画面

- 画面は縦向き
- 動画の再生エリアの下にシークバーを置き、シークバー上の各Pの位置に印（◆）を付ける
- 再生エリアとシークバーの間の空いたところに P1〜P8 のボタンを並べる。ボタンを押すとそのPのコマに移動する
- シークバーの下に再生・コマ送りのボタンを置く
- 推定したシャフトや骨格の線は、動画に重ねて表示する
- 操作ボタンの下に、表示中のコマの数値の一覧を出す

#### Pのコマの修正

- 基本：コマ送りで正しいコマを表示し、Pボタンを長押しすると、そのコマがそのPとして登録される
- 補助：シークバー上の印（◆）をドラッグして、おおまかに動かすこともできる
- Pごとに「自動に戻す」ができる（Pボタンの長押しメニューに入れる）
- 手で直したPは、ボタンの色を変えるなどして自動のPと見分けられるようにする
- Pのコマを直したら、そのPの数値を計算し直す

## 6. 保存

- 動画と解析結果（各Pのコマ、数値）を端末内に保存する
- ログインなし。クラウド保存なし
- 日付順の一覧から見返せる
- スイングごとにメモ欄を持つ（名前などを書ける）
- 生徒ごとの分類は初期版では行わない

## 7. 開発

- ネイティブで開発する（Android：Kotlin、iOS：Swift）
- Android を先に作り、iOS はあとで作る
- Pの判定ロジックと角度の計算は、両OSで同じ結果になるように、OSに依存しない形で仕様化する
- 解析処理は動画ファイルを入力にできる形で作り、カメラなしでもテストできるようにする

### 配布

- まずは社内や知り合いだけに配る（Google Play のクローズドテストなど）
- 一般公開するか、どう収益化するかは、テストの様子を見てから決める

### テスト用の動画

- 基本は自分たちで撮影する（アプリの撮影条件と同じ：正面、三脚、高フレームレート）
- YouTubeの動画は、利用規約でダウンロードが禁じられているため使わない
- GolfDB（P1〜P8にほぼ対応した正解フレーム付きのデータセット）は、ライセンスが非営利のみのため、使う場合は事前に確認する

## 8. 将来対応の一覧

- クラブ検出モデルによるシャフト推定
- 後方（ダウンザライン）からの撮影
  - 後方撮影では、打ち出し直後のボールを検出して軌道を推定し、弾道の線を動画に重ねて表示する
- 保存済み動画の読み込み
- サーバー解析（有償オプション）
- 目安の範囲、過去のスイング、お手本動画との比較
- 左打ち
- 生徒ごとの分類
- iOS 版

## 9. 未決事項

- 対応する Android 端末の下限（高フレームレート撮影と骨格推定を同時に行えるか、試作して確認する）
  - 試作に使う端末：Zenfone 9（Snapdragon 8+ Gen 1）、AQUOS R10（Snapdragon 7+ Gen 3）
  - 標準カメラアプリのスロー撮影の性能が、他のアプリからも使えるとは限らない。各端末で、アプリから使える高フレームレート（Camera2 の高速撮影機能）を確認する
- 端末が対応する最高フレームレートでは、スイングの自動検出が追いつかない場合の扱い（自動で選ぶフレームレートを一段下げるか）
